内容和声音由 AI 辅助制作，目前标记为待人工审校 / 审听。`npm run content:check -- --release` 正确报告三项尚未完成：文字审校、音频审听、儿童试用。真实 iOS / Android 软键盘、下载行为和儿童理解情况仍需实机与家长陪同试用；浏览器模拟不能替代这些验证。

没有公开部署。源词表和素材署名保存在 `content/attributions.json`，家长页可查看来源。模型和制作中间文件留在忽略目录中，网站只发布静态内容与最终 MP3。
