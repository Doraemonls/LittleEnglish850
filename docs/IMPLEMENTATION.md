# Little English 850｜开发实施说明

版本：1.0 · 日期：2026-10-10 · 状态：可开始实施

产品行为和发布条件见 [PROJECT.md](../PROJECT.md)，页面交互见 [UX 设计](ux/UX_DESIGN.md)，素材制作见 [内容规范](CONTENT.md)。本文定义实现边界、最小数据契约和任务顺序。

## 1. 组件总览与技术选择

```mermaid
flowchart LR
    Prepare["内容制作：审校文字、生成音频"] --> Assets["静态词库、图片、音频与来源清单"]
    Assets --> UI["React 页面：学习、词语书、家长设置"]
    UI <--> Rules["纯函数：拼写、复习、课程状态与统计"]
    Rules <--> State["一个应用状态：单词进度与当前练习"]
    State <--> Local["localStorage：一个版本化 JSON"]
    State --> Export["TSV 导出"]
    Assets --> Export
    Export --> File["浏览器下载文件"]
```

| 项目 | 实施选择与原因 |
| --- | --- |
| 前端 | React + TypeScript + Vite；用小组件组织四个页面，类型检查保护练习状态 |
| 样式 | 普通 CSS 与 CSS 变量，沿用 UX 颜色和尺寸；原生按钮、输入框、音频元素 |
| 页面定位 | hash 路由，支持刷新和返回，静态托管无需配置路径回退；学习路由的题目由保存状态决定 |
| 状态 | React reducer / context；拼写、日期、复习和统计写成可独立测试的纯函数 |
| 存储 | localStorage 单个键 `little-english-850`；只存小型进度 JSON，音频和图片通过文件 URL 加载 |
| 音频 | 制作阶段优先使用 Kokoro；网页使用 HTMLAudioElement 播放审听通过的 MP3 |
| 导出 | UTF-8 TSV + Blob + 浏览器下载 |
| 验证 | TypeScript、ESLint、Vitest；Playwright 验证关键浏览器流程，触屏键盘与语音另外做真机检查 |
| 包管理 | npm；首次建立工程时锁定依赖并提交 package-lock.json，后续用 npm ci 安装 |

本地环境已于 2026-10-10 检查：Node `24.16.0`、npm `11.13.0`、Python `3.12.10`、Git `2.55.0.windows.5`。当前尚无 package.json、依赖或应用源码；这些工具版本检查不代表应用已构建。首次安装后仍需验证依赖兼容性。

运行时读取单个有版本的词库。每词的最低内容字段为：稳定 `id`、标准拼写、固定 `lessonId` 和课内顺序、词性与核心含义、中文释义、图片 / 情境和替代文字、单词音频、英文例句及中文解释和音频、辅助词说明、两种选择题选项与正确项 ID、来源引用。字段的具体 TypeScript 类型在 D01 建立，完整性按 [CONTENT.md](CONTENT.md)检查。

## 3. 最小本地数据契约

### 根状态

| 字段 | 内容 |
| --- | --- |
| `schemaVersion` | 本地结构版本，首版为 1 |
| `contentVersion` | 当前固定词库版本，用于核对词 ID 和课程 |
| `words` | 以稳定词 ID 为键的当前进度；缺失条目代表未开始 |
| `session` | `null` 或唯一的新课 / 到期复习状态 |
| `settings` | 音量、语音引导开关、操作示范是否已看或跳过 |

### 每词进度

| 字段 | 值与约束 |
| --- | --- |
| `teaching` | `started` / `completed`；进入新课词卡后创建 started，三种练习完成后为 completed |
| `reviewStep` | 整数 0–3；独立通过递增至 3 后保持，失败归零 |
| `lastReviewedOn` | 最近一次完成到期复习的本地日期 `YYYY-MM-DD`，没有则为 null |
| `nextReviewOn` | 下次复习的本地日期；首次教学未完成时为 null |

`started` 的 reviewStep 为 0，两个复习日期为 null。`completed` 必须有下次复习日。显示状态由这些字段生成：缺失＝灰色，started＝浅绿，completed 且阶段小于 3＝深绿，completed 且阶段为 3＝金色。课程完成状态、累计数量和各段比例不单独存储。

### 当前练习

session 保留：模式 `lesson` / `review`、阶段 `active` / `result`、固定词 ID 序列、当前词索引与题型、当前选择题的选项 ID 顺序、输入字符串、当前词三题的完成 / 首次错误 / 提示标记，以及本轮已完成数和需再练数。新课额外带课 ID。

只保存继续练习与即时结果所需的状态。完成当前词时更新单词进度，并将 session 推进到例句；离开结果页后设为 null。自由练习、搜索文本、筛选和滚动位置用页面状态管理；它们不新增学习历史。

### 保存与重复结算

- 一次 reducer 转换先算出完整下一状态，再将 words 和 session 一起写入同一个 localStorage 键；每次有效输入、错误、提示、继续和设置变更都保存。
- 成功结算当前词时，同时更新日期 / 阶段、结果摘要和 session 位置；刷新不能重复结算。结果页刷新仍可显示当前摘要，离开后释放。
- 保存失败保留当前内存状态并提示重试，避免将未保存状态显示为已保存。解析失败、结构版本或词 ID 不兼容时保留原始存储并停止覆盖，显示可理解的错误。
- 应用按单个学习标签页使用；另一个标签页写入状态时，通过 storage 事件让旧页面停止作答并重新载入最新状态，避免继续用旧进度写回。

## 4. 必须统一的实现细节

| 场景 | 处理 |
| --- | --- |
| 新课词序 | 按固定课程顺序学习，跳过已经完成首次教学的词；逐词完成，当前只会有一个新词处于 started |
| 复习队列 | 创建时取最多 10 个到期且今天未判定的词；按到期日和词表顺序排序，保存队列后续学 |
| 跨日续学 | 保留题目与提示标记，在三题完成日结算；下次日期从该完成日按本地日历加天，不使用固定毫秒数跨天 |
| 题目正误 | 错误和提示标记只能从 false 变为 true；重试或返回题目不撤销该标记 |
| 答案查看 | 当前未结算的复习词在词语书打开详情或做自由练习时，设置当前词提示标记；正式状态和日期仍在三题完成时结算 |
| 拼写输入 | 用真实文本输入控件，处理 beforeinput / input / composition；功能键不计错，粘贴与整词替换不通过；禁用自动补全 / 自动纠错仍需真机验证 |
| 音频 | 统一播放器，同一时刻一段；点击重听不改变输入，离开题目停止音频；失败保持该题未完成 |
| 结果页 | 新课与复习分别显示本轮完成数量；最后一课结束后不显示「再学 5 个词」 |
| 小进度段 | 按真实词数计算比例，不人为增加段宽；颜色配文字图例及读屏说明 |
| TSV | 按固定词序输出完整 850 行，中文表头、UTF-8（带 BOM 便于表格软件识别）；日期为空写空列，导出时间带时区 |

TSV 列顺序固定为：`导出时间、词表版本、词ID、单词、课次、学习状态、连续独立通过阶段、最近复习判定日、下次复习日`。阶段值为 0–3，3 表示已经达到连续三次标准，不是历史累计次数。导出时合并固定内容与当前进度，未开始词也生成一行；保持各列的 tab / 换行转义一致。

以下任务均待实施。D01 和 D02 完成后可进入第一课交互；内容量产在样例通过后展开。

| 任务 | 工作与产物 | 完成证据 |
| --- | --- | --- |
| D01 固定内容基线 | 核对 850 个词，固定词 ID、词性、课次和来源版本；建立词条类型与内容检查器；准备第一课 5 词及 15 个代表词 | 850 个唯一 ID 和 170×5 编排检查通过；20 个样例字段完整，词义和句型已审校 |
| D02 建立工程 | 建立 React / TypeScript / Vite、CSS 基础、页面定位和命令；建立最小数据类型与本地保存 | 安装与锁文件可复现；页面可启动，类型和构建通过；空进度能保存与读取 |
| D03 完成第一课 | 首页、词卡、两类选择题、拼写、例句、暂停 / 续学和本课结果；接入样例图片与审听音频 | 第一课 5 词完整走通；在错误后和输入中刷新仍续接；手机键盘下可完成；对应 A02、A03、A05 |
| D04 复习与进度 | 实现日期、独立通过、失败归零、互斥颜色和派生统计 | 日期边界、重复结算和提示资格测试通过；对应 A04、A06 |
| D05 查阅与家长页 | 词语书、固定目录、自由练习、家长统计、声音设置和单按钮 TSV | 查询、返回、唯一续学、当前词查答案标记和导出检查通过；对应 A07、A08 |
| D06 完整内容 | 依据样例质量制作并审校剩余 830 词，生成完整音频 / 图片与来源清单 | 所有 850 词齐全、可读、对应一致，授权与人工审校记录完成；对应 A01 |

D03 的儿童样例验证重点是：是否能听懂操作、辨别选项、逐字输入、清空后重试，以及理解首页进度。实际材料制作速度从 20 词样例测量，剩余工期按审校通过速度估算。

工程创建时提供以下 npm scripts；**当前仓库尚不能执行这些应用命令**：

| 命令 | 负责验证 |
| --- | --- |
| `npm run dev` | 本地交互开发 |
| `npm run typecheck` | 内容与状态类型一致 |
| `npm run lint` | 代码静态检查 |
| `npm run test` | 一次性运行拼写、日期、复习、状态转换、导出单元测试 |
| `npm run content:check` | 默认全量检查；样例阶段通过显式 sample 参数检查，报告必须标明样例范围 |

| `npm run preview` | 查看生产构建 |
| `npm run test:e2e` | 浏览器中的首次学习、刷新续学、查阅与 TSV 下载 |

规则测试覆盖首 / 中 / 末字母错误、提示后重试、首次教学与复习区别、跨月 / 年 / 夏令时日期、每天一次、逾期、重复提交、最后一课、自由练习隔离及当前词查答案。存储和导出测试覆盖未开始词、损坏存储、写入失败、中文字符及空日期。

桌面至少验证 Chromium、Firefox、WebKit；手机和实际平板检查 Safari / Chrome 对音频播放、英文软键盘、可见焦点和下载的行为。浏览器模拟不能代替真实键盘检查，也不能代替人工审听与儿童试用。
