# 小小英语 · Sunny Memphis 设计

2026-10-19 · [设计总览](index.html) · [页面与交互说明](../UX_DESIGN.md) · [已会单词跳过设计](../SKIP_WORD_DESIGN.md)

首页连接正式学习、词语书与家长页；家长页连接中英文关于页。学习沿用“词卡 → 看词选意思 → 听音选意思 → 拼写 → 句中听读”，到期复习从拼写开始。[页面关系图](06-interactions.svg) 展示全站连接。

本目录是网站采用的视觉方案，统一替代此前的设计稿。SVG 用于查看页面布局；实际交互由 React 页面实现，样式位于 `src/app/styles.css`。07 的已会单词跳过流程已进入应用实现。

颜色集中在主按钮、播放入口和小图形上，白色阅读区保留充足留白。面板使用浅边线、约 16 px 圆角与轻阴影；控件用更深的边线保持可辨认。英文提问、例句和句子小帮手均为 400 常规字重，重点单词用大字号突出。

[设计参数](design-tokens.json) 按基础色、语义用途和组件三层组织。SVG 内嵌颜色，可独立打开。系统字体和 emoji 随设备略有差异。

首页和家长图板中的进度是示例：9 个记牢了、85 个学过、1 个正在学、755 个未开始。网站始终读取当前浏览器的真实进度，首页只显示色条和三个短标签。“记牢了”表示连续三次独立复习通过，仍会定期巩固。

学习界面使用简短英语：Lesson 1、Pause、Listen、Hint、Continue、Correct!、Try again。中文释义、例句翻译和选项中文发音保留。原有中文语音引导继续由家长页开关控制。

| 视图 | 提问 / 操作 |
| --- | --- |
| 词卡 | Listen / Try it / I know this word（仅新课） |
| 看词选意思 | What does **apple** mean? |
| 听音选意思 | What do you hear? / Listen again |
| 拼写 | Listen and spell. |
| 句中听读 | Read a sentence. / Next word |

选项为中文加词条已有 emoji，例如“苹果 🍎”，右侧扬声器独立播放中文。所有选项在作答前样式相同；正确后出现绿色和勾形。听音题的答案在单词音频完整播放后开放。

词卡、句中听读和词语书详情共用例句按钮：英文句子与扬声器组成至少 60 px 高的整行点击区，长句自然换行。点击、Enter 或空格均可播放；播放时句子保持可见，学习步骤不前进。中文翻译在下一行，辅助词按需展开。

拼写使用单一原生输入框。逐字核对、输错清空、焦点保留和刷新续学沿用既有行为；字母数量由学习规则处理。手机键盘出现时缩小播放入口，并将输入框滚动到可见位置。

新课词卡在 `Try it` 下方提供白底次要按钮 `I know this word`。点击后先确认；确认文案说明当前词会成为“学过”并在以后复习，不会直接成为“记牢了”。保存成功才进入下一词，复习和自由练习不显示该入口。视觉状态与完整规则见[已会单词跳过设计](../SKIP_WORD_DESIGN.md)。

## 背景装饰

小圆点、空心圆和短波纹固定散布在留白处，每屏最多两枚小 emoji。装饰使用 `aria-hidden` 和 `pointer-events: none`，位置不随点击变化。手机优先隐藏较大的波纹与圆环。

学习题背景只放抽象几何图形，保持答案区域清楚。家长页与关于页减少点缀，统计和正文使用白色面板。

## 清晰度与适配

正文文字组合达到 WCAG 4.5:1；控件边线与外侧背景达到 3:1。例如墨蓝灰在白色、明黄、晴空蓝上的对比度分别为 10.65:1、6.93:1、5.19:1。颜色和文字、勾形共同表达状态。

所有按钮至少 44 px 高；焦点采用清楚的外圈，原生按钮、输入框和弹窗支持键盘。家长页在桌面使用两列，手机变为单列；学习卡与首页保持居中。页面尊重系统减少动态效果设置。
